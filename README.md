\# Bài tập Git và GitHub



Repository này được tạo nhằm thực hành các thao tác Git và GitHub cơ bản.



\## Mục tiêu



\- Tạo repository GitHub

\- Clone repository về máy

\- Thực hiện commit

\- Push mã nguồn lên GitHub

\- Pull để đồng bộ mã nguồn

\## Nội dung thực hành



Thực hành quy trình làm việc cơ bản với Git và GitHub bằng dòng lệnh.
## Mô tả dự án

Dự án được thực hiện nhằm thực hành quản lý mã nguồn bằng Git và GitHub trong môi trường phát triển phần mềm mã nguồn mở.
